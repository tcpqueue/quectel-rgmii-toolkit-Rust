移远高通系列5G模块配置与维护

从连接模块到安装后台，按步骤完成配置；已有 ADB 可直接进入安装。

连接与准备

仅适配已识别的移远高通 RG/RM 型号。已有 ADB 连接可直接前往安装。

1. 选择 AT 串口

优先选择名称中含 Quectel 和 AT 的端口。请先关闭其他串口软件。选择端口不会自动发送指令。

尚未识别连接模块后刷新串口，选择端口并点击识别。
型号
固件
厂商
设备标识

2. 开启 ADB 连接

先检查 USB 配置倒数第二项：1 或 2 表示 ADB 已开启，直接跳过解锁；仅在值为 0 时置为 2，启用免授权 ADB。保留其他 USB 设置，重启需单独确认。

前往安装 →

3. 联网配置 · PCIe / ECM / RNDIS

网卡型号以转接板为准；指令返回 OK 仅表示配置被接受，网口是否联网仍需检查网线、SIM 和 APN。

设备信息 · 手动读取，不持续轮询

SIM、信号、温度、USB 和网口配置分项显示。不支持的查询会标记为“固件未提供”。

高级 AT 工具

每行一条指令，最多 32 条。执行前确认完整列表；遇到错误立即停止。不会自动运行或循环发送。

操作记录
