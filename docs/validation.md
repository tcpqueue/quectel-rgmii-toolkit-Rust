# 兼容性与真机验证

本次迁移以已修复的 Go 版为基准，保留同一套前端和接口。兼容性由原 Go 函数输出、伪终端事务测试、浏览器测试和 RM520N-EU 实机测试共同检查。本文区分已实测项目与尚未执行的操作，不将命令构造一致等同于所有固件行为都已验证。

## AT 核对

| 范围 | 检查方式与结果 |
| --- | --- |
| 总览、设备、网络、频段、设置、小区扫描解析 | 原 Go 解析函数生成的 264 个样本对照通过 |
| 设置与网络写命令 | 28 组 Go 页面动作的命令字符串逐项对照通过 |
| 复合命令 | 保留分号组合及结尾 `\r\n`，伪终端验证实际写出的字节 |
| 超时 | 普通命令 1 秒，关闭 MPDN 规则 10 秒，小区扫描 120 秒；复合命令累加 |
| 缓存 | 131 组 Go 策略样本对照；动态读数 3 秒、网络配置 30 秒、一般配置 60 秒、静态信息 600 秒、短信 5 秒；启动等待约 35 秒，型号查询可立即执行 |
| SMD 串口 | `/dev/smd11` 原生读写，工作队列串行化，持久读取线程，断开后重新打开；重复读者拒绝启动 |
| 短信读取 | 48 组 Go 样本对照，包含原测试动态生成的长短信与 PDU；覆盖 UCS2、GSM7、换行及分段合并 |
| 短信发送 | 号码补全、UCS2 PDU、分段、提示符、Ctrl-Z、结束响应；伪终端验证完整事务，不被其他 AT 插入 |
| 人工 AT | 真机执行 ATI、CGMM、CSQ、QENG、QTEMP、CPIN 只读查询并确认成功响应 |

短信列表命令与 Go 版保持一致：

```text
AT+CSMS=1;+CSDH=0;+CNMI=2,1,0,0,0;+CMGF=0;+CPMS="ME","ME","ME";+CMGL=4
```

以下差异属于明确的修正或资源限制：

- 不认识的人工命令不加入后台刷新缓存，避免未知写命令被重复执行。
- AT 缓存限制为 64 项、1 MiB 响应内容，工作队列限制 16 个请求。
- 旧 Go 短信代码可能将缺失分段标识转换成字符串 `<nil>`，误合并无关短信。Rust 不生成这个伪标识；旧格式短信仅按同发件人、相邻存储索引和五秒时间范围合并。对照测试只排除这个无效字段，并额外验证无关短信不合并。
- 发送含非 BMP 字符的短信时按 UTF-16 单元分段，保证不超过 PDU 载荷限制。
- 独立 AT 命令在服务运行时会返回“读者已存在”，避免串口抢读；服务中的 Web AT 终端不受影响。
- 型号缓存重试策略、部分错误文本、请求数量上限及证书 SAN 自动发现不与 Go 的内部实现完全相同。

## 真机测试

测试设备：**RM520N-EU，ARMv7，Linux 5.4.210，182,516 KiB 系统内存**。通过 Windows ADB 安装 ARM 静态可执行文件。

- 安装成功，systemd 服务处于 active，旧 Go 进程退出；应用权限 777，认证文件 600，根目录恢复 ro。
- 原 Web 登录密码和 root 初始化标记保留；Web 登录、设备信息及所有页面只读 API 正常。
- 真实 5G SA 信号、SINR、温度与 Ping 可读取；没有 4G 数据时不显示 4G 读数。
- 中文、英语、俄语、阿拉伯语登录和页面切换通过；桌面、390px、320px 布局及图表像素检查通过。
- 在其他页面刷新后返回总览，更新时间继续变化，曲线继续加载。
- 原生控制台使用系统 root 认证并执行 `id`，确认 PTY 可用。
- 持久化 Ping 目标切换后正确清空旧目标历史，恢复 `www.baidu.com`；写入后根目录为 ro。

连续 310 秒不请求历史接口后，返回 **300 个 Ping 点、60 个信号/温度点**，采样间隔中位数分别为 **1,000 ms、5,000 ms**。本轮 300 个 Ping 均收到响应；按相邻 RTT 独立重算的 Jitter 与接口完全一致。同期应用文件大小、修改时间及 root 密码文件校验未变化，根目录保持 ro。此检查反映应用文件行为，不等同于测量整个固件的 NAND 物理写入量。

## 资源对比

同一设备、同一 Ping 目标，两个后端依次单独运行，绑定本机回环测试端口以排除现有浏览器访问。每次预热 30 秒，然后采样 60 秒。后台开启 1 秒 Ping、5 秒信号采集。Go 数据包含主进程和 SMD 辅助进程。

| 指标 | Go | Rust |
| --- | ---: | ---: |
| 后台 CPU / 全机 CPU 时间 | 1.455% | 0.445% |
| 进程 RSS 合计 | 9,336 KiB | 1,436 KiB |
| 进程 PSS 合计 | 7,428 KiB | 1,432 KiB |
| 线程数合计 | 9 | 3 |
| ARM 可执行文件 | 7,930,018 字节 | 4,148,012 字节 |

本次后台样本中 CPU 降低约 **69%**，PSS 降低约 **81%**，可执行文件缩小约 **48%**。Go 对照程序从 tmpfs 运行，Rust 从安装目录运行；PSS 对共享页分摊，RSS 合计可能重复计入 Go 两个进程共享的代码页。数据为一次短时测试，受频率调节、网络状态及缓存影响，不能外推到所有负载。

正式安装后的另一轮页面访问场景中，Rust RSS 为 **3,140 KiB**、PSS 为 **3,136 KiB**，线程数仍为 3。首次常规采样发现有额外浏览器连接，因此未用它与无浏览器的 Go CPU 数据直接比较。历史数组达到五分钟上限后仍保持固定大小。

## 自动验证

`cargo test --locked` 共 **23 项测试通过**，测试内包含多组 Go 对照样本。Clippy 严格检查通过。另通过 HTTPS 证书链校验、HTTP 跳转与重启不重复写证书检查，以及 Windows 可执行文件启动、登录、模拟读数和密码修改检查。

## 未进行的实机操作

没有在用户 SIM 上实际发送收费短信或删除短信，也没有为了验证而改写 IMEI、切换 USB 模式、重置 AT 设置、重启模块或执行会中断当前连接的锁频、锁小区操作。这些操作已核对接口与 AT 命令构造，但仍需相应硬件场景进一步验证。真实 root/Web 密码本次未改动，修改与会话失效流程在隔离环境验证。

本次结果支持在当前 RM520N-EU 上使用与继续测试；不代表所有型号、固件和网络场景均已完成一比一实机验证。
