# 资源与存储

## 进程与内存

后端使用单线程异步运行时、一个 AT 工作线程和一个串口读取线程，直接访问 `/dev/smd11`，不启动 Go SMD 辅助进程或 `socat`。AT 指令串行执行，短信的提示符、PDU 和结束响应属于同一事务；网页 API 请求可并行等待，扫描小区期间读取缓存或非 AT 数据不必排队。

历史数据采用固定长度环形数组和定点数，三类历史的原始数组合计不超过 13,200 字节。AT 队列最多 16 个请求，缓存最多 64 项、响应内容合计最多 1 MiB。这些是内部缓冲区上限，不代表程序总内存占用。

v0.1.0 在 RM520N-EU 同条件后台采样中，CPU 约 1.46% → 0.45%，PSS 内存约 7.25 MiB → 1.40 MiB（对比 Go 版）；正常访问页面时约 3.1 MiB。采样条件见 [验证记录](validation.md)。

短信转发默认关闭，HTTP 客户端在首次推送时才初始化。

## 写入 NAND

持久化设置统一执行 **根目录 rw → 写临时文件 → 同步 → 原子替换 → 根目录 ro**，内容不变时跳过。曲线、会话、锁文件留在内存或 tmpfs。服务只在 `/tmp` 为 tmpfs 时保留当次启动消息或退出错误，不输出持续日志；控制台不写 shell 历史。只有启用短信自动删除后，才为已转发的短信保存删除凭据。应用目录及可执行文件权限为 `777`，认证文件为 `600`。

## 后台 DNS

Ping 与短信转发分别使用受限的独立解析器，不占用 Tokio 网页文件读取线程池。每个解析器同时最多执行一个系统查询，等待超时后保留原任务；错误后间隔 5 秒重试，成功结果缓存 60 秒。HTTP 解析保留最多 16 个 IPv4 / IPv6 地址供连接回退使用，URL 主机名与 TLS 校验保持不变。系统 DNS 一直卡住时会影响对应域名请求，但不会堆积解析任务。

## 短信自动删除

删除必须同时满足已持久化的成功凭据、短信位置与指纹一致、日期已过 24 小时、单调计时已过 24 小时。程序重启后重新进行单调计时；系统时间早于 2020 年或与单调时钟的偏差超过 120 秒时，暂停并重新计时。这样会延后删除，避免设备从 1970 年校准时间时提前清理。等待状态只在内存中，不新增定时落盘；重启后不补发短信。

## 图表与查询

首次请求返回完整五分钟历史，后续携带每类采样的游标，只接收新增数据。游标包含进程标识与目标配置代数；重启、目标变化或游标不匹配时恢复全量。分别跟踪 Ping、信号和流量的时间，避免遗漏晚完成的信号采样。汇总数据始终按完整五分钟窗口计算。前端合并、去重、淘汰过期点；无新点时跳过对应图表重绘。

300 个 Ping 点附近的固定测试样本中，全量响应 22,458 字节，增量响应 629 字节。此结果只代表该样本的传输量，不能据此推算实际 CPU 或内存降幅。

非监测 AT 缓存超过两分钟无人访问后停止主动刷新；重新访问正常恢复。

## 可调的后台采集

延迟监测与信号/流量采样可在总览“监测设置”中分别关闭或调整间隔（Ping 1–300 秒，采样 2–300 秒），通过 `POST /api/telemetry/schedule` 保存到 `monitor.json`，修改后后台任务立即按新计划运行，不需要重启。前端轮询间隔随之放慢，最长 10 秒一次。

同一份 AT 应答只记录一次：后台采样与总览页刷新共用缓存时间戳去重，所以关闭后台采样后，打开总览页时仍能得到信号与速率，不会产生重复点或虚假的零速率。流量速率允许的最大采样间隔为采样周期的 3 倍（至少 15 秒），间隔更长视为采样中断。

短信转发在 AT 口收到 `+CMTI` 后立即读取收件箱。确认该端口能收到通知后，兜底轮询从 10 秒放宽到 60 秒；兜底读取同时会重新设置 `AT+CNMI`，模块重启后通知可自动恢复。

## 连接预算

每个 HTTP / HTTPS 监听端口最多 32 条连接；API WebSocket 最多 8 条，每条同时最多 8 个请求（超出返回 429），终端最多 2 条。请求头等待上限 10 秒，API 正文读取上限 5 秒，HTTP 正文与 API WebSocket 消息上限 64 KiB，终端消息上限 16 KiB。AT 操作自身的等待时间不受正文读取超时影响。

## 验证

- Rust 测试覆盖时间跳变、重启延后删除、目标切换、晚完成采样、完整窗口统计、闲置缓存和 DNS 取消后的任务保留。
- `node tests/offline-dns.cjs`：模拟 DNS 立即失败、25 秒阻塞、IP 目标和连续转发测试，确认网页可访问且查询不堆积。解析替身不连接外部推送平台。
- `node tests/resource-limits.cjs`：增量合并、重复响应、过期点、超大正文、慢正文、连接上限、慢请求头回收及后续恢复。
- `node tests/browser.cjs`：中文、英语及 1440 / 1024 / 390 / 320 像素宽度的页面回归。
- `node tests/monitor-schedule-browser.cjs`：监测设置的校验、保存、图表标签、拨号状态回退、页面驱动采样、持久化、多语言与手机布局。

构建与测试均在 Linux 原生目录执行。短信测试仅使用模拟数据，不在真机发送或删除短信。
