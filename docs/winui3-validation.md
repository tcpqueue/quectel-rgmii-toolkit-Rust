## 移远高通准备流程

单元测试使用脚本化的模拟 AT 链路：USB 倒数第二项为 1 或 2 时，断言不发送 QADBKEY 查询、密钥、USB 写入或重启；确认期间状态变为已开启也直接跳过。值为 0 时重新校验 USB 配置与挑战码，只有密钥被接受后才写入，并复查全部接口字段。密钥拒绝、配置变化、身份不匹配、取消和读回失败均停止后续操作。

设备信息与高级 AT 查询的响应写入界面操作记录，默认只存电脑内存，手动保存至电脑。参考工具的 Python 源码不包含在安装包中；C# 独立实现解锁算法与串口通信。WinUI、.NET 和串口依赖只在电脑运行，模块固件与 Rust 后端未修改。

本次检测到的 COM13 / COM14 为蓝牙端口，未发现移远 AT 串口或 ADB 设备。新增解锁与网口写入流程通过模拟验证，尚未在真机上执行；没有发送、读取或删除真实短信，也没有重启或恢复出厂。
