# 原生 WinUI 3 安装器验证

2026-09-07，Windows 11 x64。安装器版本 1.1，模块端仍为 Rust 0.2.3。

界面使用 Microsoft.UI.Xaml 原生控件，XAML 编译为 XBF，并随资源索引打包。Windows App SDK WinUI 1.8 与 .NET 8 采用自包含部署。外层启动器仅负责解包、启动、透传退出码和清理临时文件，无 WPF 界面。

| 检查 | 结果 |
| --- | --- |
| Windows 安装逻辑 | 27 项通过，包括设备兼容性、上传失败、网页异常、自定义端口、升级保留和只读诊断 |
| WinUI 界面流程 | 24 项通过，包括按钮状态、结果展示、报告、无效端口拦截、错误设备保护和实时日志 |
| 实时日志 | 模拟 ADB 等待界面显示中间输出，确认进程退出前可见 |
| 正式单文件启动 | 解包后原生程序自检通过，退出码正确传回 |
| 内置资源 | 必需设备文件存在，内置 ADB 可执行；未连接设备 |
| 正式 EXE 界面渲染 | 浅色、深色、小窗口均成功；小窗口隐藏侧栏，主体可纵向滚动 |
| 构建 | 锁定 NuGet 依赖，编译警告视为错误，生成自包含 x64 程序 |

最终 EXE 约 66 MiB，新增运行库仅在 Windows 电脑使用，不上传到模块。首次解包会使用电脑临时磁盘空间；报告保存到 `%LOCALAPPDATA%/SimpleAdmin/Reports`。不终止共享 ADB 服务，仍被占用的临时文件交由系统后续清理。

本次电脑未连接模块，没有重复执行真机安装，也未发送或删除短信。Windows 10 19041 是编译与启动器声明的最低版本，尚未在独立 Windows 10 或全新系统镜像中实测；已在当前 Windows 11 验证自包含 EXE 的启动和界面。
