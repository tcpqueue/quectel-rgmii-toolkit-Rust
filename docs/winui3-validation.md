## RM520N-EU 真机检查

设备型号 RM520N-EU，固件 RM520NEUDAR03A08M4G，AT 串口 COM7。

读取的 USB 配置为：

    +QCFG: "usbcfg",0x2C7C,0x0801,1,1,1,1,1,2,0

原来的串口实现关闭 DTR/RTS，实测会出现超时和响应积压；开启后一次性收到此前多条响应。修正为开启 DTR/RTS，并在建立事务前等待接收缓冲区安静、清理积压响应。使用实际 WinUI 识别与检查流程验证，正确读取倒数第二项 2，跳过解锁，不发送密钥或 USB 配置写入。

VID 按数值校验为 2C7C，PID 接受原始有效的 16 位编号，生成指令时保留原文本。确认后再次核对 USB 配置，倒数第二项为 0 时直接置为 2，并复查全部字段；为 1 或 2 时跳过。不计算、不查询、不发送 QADBKEY。解析失败时显示具体原因与原始 USB 返回值。

模块 ADB 不支持 shell -T；已使用其支持的 exec-in，在 /tmp 中验证凭据传输及 SHA-256 一致性，并用新 ARM 程序的 install-credentials --check 验证输入。临时文件已删除，没有更改现有账号、密码或服务。

最终 ARM 产物另在模块的 /tmp（tmpfs）启动隔离的模拟实例，实测 HTTP 监听从 18924 切换到 18925、端口文件保存、用户名修改及保留原密码重新登录。测试通过 ADB 转发访问，不使用生产凭据，不发送 AT 指令；结束后停止临时进程、删除临时文件并移除转发。防火墙和根分区持久化路径未在这个模拟实例中执行。

三种联网方案通过模拟指令序列验证：仅在存在 MPDN 规则 0 时先关闭，随后配置所选数据接口并启用 QMAPWAC。未在真机执行网口切换、重启、恢复出厂或短信操作。

## 存储与兼容性

密码通过标准输入传输，不出现在命令行、报告或电脑临时密码文件中；模块凭据文件只在 /tmp 暂存，完整性校验通过后才继续安装。预校验在停止旧服务前执行，保存发生在安装脚本挂载读写期间，完成后同步并恢复只读。

依赖仅在 Windows 电脑运行，不上传到模块。Windows 10 19041 是最低目标版本，当前完成 Windows 11 验证，尚未在独立的全新 Windows 10 镜像中测试。
正式单文件已通过启动自检、内置资源校验和浅色、深色、小窗口渲染。工具 1.3 与模块 Rust 0.2.4 编译产物及校验和同步提交。

## 网页 WebUI 设置

新增登录保护的设置读取与 HTTP 端口修改接口。修改账号、密码或端口必须验证当前 Web 密码；账号修改支持保留密码并撤销旧会话。端口切换先绑定新端口，保存配置后切换监听，保留全局连接数量限制；不重启模块或应用，原监听不再接受新连接。新端口沿用固件针对 rmnet 接口的 HTTP 阻断规则。
